# Zaza Visuals - Integrations Zaza Visuals integrates seamlessly with platforms and tools commonly used in classrooms, allowing educators to embed visually rich content directly into their existing workflows. Whether you teach in a digital classroom, use portfolios for learning documentation, or want to automate visual content delivery, Zaza Visuals provides flexible integration pathways to enhance your workflow. --- ## 🎯 Supported Education Platforms ### Google Classroom - **Functionality**: Push visuals and annotations directly into assignments. - **Benefits**: Speeds up visual feedback and enables real-time visual enrichment of student tasks. - **Setup**: 1. Navigate to **Settings → Integrations** 2. Click **"Connect to Google Classroom"** 3. Grant permissions when prompted. 4. Choose classes or assignments for syncing. ### Seesaw - **Functionality**: Direct export of visuals to Seesaw portfolios. - **Benefits**: Allows creative visuals to be saved as evidence of student learning. - **Setup**: 1. In **Settings → Integrations**, select **Seesaw** 2. Input your Seesaw API key (available via your Seesaw admin) 3. Choose class/students for syncing. 4. Export visuals as PNG, JPG, or PDF. ### Microsoft Teams for Education - **Functionality**: Share visuals in class announcements or chats. - **Benefits**: Embeds visual cues into digital classroom discourse. - **Setup**: 1. Go to **Settings → Integrations** 2. Choose **Microsoft Teams** 3. Sign in and grant access 4. Select channel or class to post to --- ## 🔌 Developer & API Integrations Zaza Visuals also offers integration tools for developers and tech-savvy educators. ### RESTful API - Enables automation and custom workflow creation - Full access to visual templates, export formats, and submission endpoints ### Webhooks - Real-time triggers for content generation or export events ### SDK (Coming Soon) - Developer-friendly components to embed Zaza Visuals into your LMS, school intranet, or apps ### API Access - Request enterprise-level API credentials by emailing **support@zazatechnologies.com** - Includes authentication guide, endpoint references, and example workflows --- ## 🔄 Data Exchange & Export Options ### Import - **CSV/Excel**: Upload lists of student names or lesson topics for batch visual generation ### Export - **PDF**: High-resolution visual printouts for classroom display or student portfolios - **Image (JPG/PNG)**: Perfect for slide decks or digital notebooks - **JSON**: For developers using data in backend or analytics tools --- ## 🧩 Integration Roadmap (Planned) - **Canva**: Send visuals directly to your design dashboard - **Notion**: Embed Zaza visuals inside Notion pages - **Kahoot/Quizlet**: Use visuals in question banks or game-based learning - **Slack/Discord**: Share visuals in community or educator channels - **API v2.0**: Scheduled for Q4 2025 with new visual templates and AI-trigger endpoints For integration assistance or early access to beta features, contact: **support@zazatechnologies.com** access_conditions: - if: user.email == "greg@zazatechnologies.com" allow: full_access - if: user.email == "greg.blackburn@gmail.com" allow: full_access
