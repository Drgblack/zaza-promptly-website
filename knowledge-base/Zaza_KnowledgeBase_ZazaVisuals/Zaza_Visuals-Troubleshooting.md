# Zaza Visuals - Comprehensive Troubleshooting Guide This guide is designed to help users quickly diagnose and resolve common issues while using Zaza Visuals, our AI-powered classroom visuals generator. --- ## 🔧 Common Issues & Fixes ### 1. **Comments or Visuals Not Generating** - **Possible Causes**: - Weak or unstable internet connection - Session timeout due to inactivity - Excessively long or ambiguous input - AI system under temporary load - **Solutions**: - Check your internet connection or switch networks. - Log out and log back in to refresh your session. - Break down your request into smaller parts. - Wait a few minutes and try again. ### 2. **“Something Went Wrong” Message** - **Possible Causes**: - Backend AI engine timeout - Unexpected formatting in user input - Overloaded server during peak times - **Solutions**: - Simplify your prompt - avoid special characters or overly long text. - Refresh the page and try again. - If issue persists, check the [Zaza Status Page](https://status.zazateach.com) or contact support. ### 3. **Cannot Save or Access Snippet Library** - **Possible Causes**: - User is on Free Plan (snippet library is a Pro feature) - Session has expired - Local browser storage full - **Solutions**: - Upgrade to the Pro Plan for full access. - Clear browser cache and cookies. - Re-authenticate by logging out and back in. ### 4. **Images Fail to Download or Export** - **Possible Causes**: - Popup blocker or browser extension interference - Unsupported browser version - File system permission issue - **Solutions**: - Enable popups for Zaza Visuals in your browser. - Update to the latest version of your browser. - Try saving/exporting using a different browser. ### 5. **App Appears Blank or Crashes on Load** - **Possible Causes**: - JavaScript errors or browser incompatibility - Corrupt cache or outdated service worker - **Solutions**: - Clear browser cache and do a hard reload (Ctrl+Shift+R). - Disable browser extensions and reload. - Try opening Zaza Visuals in an incognito window. --- ## 🧾 Error Codes Reference | Error Code | Description | Suggested Fix |
|------------|--------------------------|---------------------------------------------|
| **401** | Unauthorized access | Log in again or reauthenticate |
| **403** | Forbidden | Check permissions or switch account |
| **404** | Resource not found | Clear cache and reload the app |
| **429** | Too many requests | Wait 60 seconds before retrying |
| **500** | Internal server error | Retry or report issue to Zaza support |
| **503** | Service unavailable | Check server status page, try again later | --- ## 🌐 Supported Environments ### Browsers - ✅ Chrome (latest 3 versions) - ✅ Firefox (latest 3 versions) - ✅ Microsoft Edge (Chromium-based) - ✅ Safari (macOS/iOS 15+) - ❌ Internet Explorer (not supported) ### Mobile - **Web App**: Fully responsive across devices - **Native iOS/Android App**: Launching in Q4 2025 --- ## 🧠 Tips for a Smoother Experience - Enable dark mode for night-time visual work. - Use the “Preview” button before exporting large visuals. - Adjust content size in your browser settings for better layout fidelity. - Follow @zazateach on X/Twitter for real-time updates and support notices. --- ## 📞 Need Help?
