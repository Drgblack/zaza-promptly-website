## User Guide & Best Practices

### Getting Started
1. **Sign Up**: Visit zazapromptly.com and create account with school email
2. **Verification**: Confirm email address and complete profile
3. **First Comment**: Use guided tutorial to generate first comment
4. **Customization**: Set up personal tone preferences and snippet library
5. **Integration**: Connect with existing tools and systems

### Optimal Workflows

#### Standard Comment Creation
1. **Context Input**: Provide 2-3 sentences about student performance
2. **Tone Selection**: Choose appropriate communication style
3. **Generate**: Click generate and wait for AI response
4. **Review**: Read generated comment for accuracy and tone
5. **Edit**: Make any necessary adjustments
6. **Save**: Copy to clipboard or save to snippet library

#### Bulk Processing
1. **Prepare Data**: Organize student information in spreadsheet
2. **Upload**: Import student data through bulk interface
3. **Configure**: Set tone and style preferences for batch
4. **Generate**: Process multiple comments simultaneously
5. **Review**: Individually review each generated comment
6. **Export**: Download in preferred format

#### Parent Communication
1. **Template Selection**: Choose collaborative tone preset
2. **Context Addition**: Include specific examples and observations
3. **Cultural Sensitivity**: Ensure appropriate language and style
4. **Preview**: Check tone and clarity before sending
5. **Follow-up**: Use snippet library for consistent messaging

### Tips for Maximum Effectiveness
- **Be Specific**: Provide concrete examples in context input
- **Use Keywords**: Include subject-specific terminology
- **Review Always**: AI generates drafts, teacher expertise finalizes
- **Build Library**: Save effective phrases and structures
- **Stay Consistent**: Use similar tone across all communications
