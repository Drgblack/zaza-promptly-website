All data processing happens within the European Union using secure, GDPR-compliant servers.

## Data Location

**Processing:** EU-based servers only
**Storage:** Temporary processing in secure EU data centres  
**Backups:** EU-based backup systems with encryption
**No US servers:** Data never leaves European jurisdiction

## Security Measures

- Bank-level encryption in transit and at rest
- ISO 27001 certified data centres
- Regular security audits and monitoring
- Access controls and audit trails

## What Gets Processed

**Temporarily:** Text you input for comment generation
**Not stored:** Student names, personal details, or sensitive information
**Not retained:** Input text is deleted after your session ends
