Yes! Promptly works perfectly on Chromebooks and is designed to work within school network restrictions.

## Chromebook Compatibility

Promptly runs in your web browser, so it works on any Chromebook with:
- Chrome browser (already installed)
- Internet connection
- Teacher login credentials

No additional software installation required - perfect for schools with strict device policies.

## School Network Considerations

**HTTPS security:** Promptly uses secure connections that work with most school firewalls
**Minimal bandwidth:** Efficient design that works on slower school networks  
**Standard ports:** No special network configurations needed
**Education-friendly:** Designed specifically for school IT environments
