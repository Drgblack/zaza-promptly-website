If downloaded resources aren't opening, this is usually due to browser security settings or file type associations.

## Common Solutions

**Check your downloads folder:** Files might be there but not opened automatically
**Try a different browser:** Chrome, Firefox, Safari, or Edge might handle files differently  
**Disable popup blockers:** Some browsers block download popups
**Allow downloads from our site:** Add zazapromptly.com to your trusted sites

## File Type Issues

**PDF problems:** Ensure you have a PDF reader (Adobe Reader, built-in browser viewer)
**Template files:** Check you have appropriate software (Word, Google Docs, etc.)
**Mobile devices:** Some files work better when opened on desktop/laptop

## School Network Restrictions

**Blocked downloads:** School firewalls might prevent file downloads
**File type filtering:** Some schools block certain file types for security
**Proxy settings:** School networks might interfere with downloads

## Alternative Access

If downloads still don't work:
- Try from your personal device/network
- [Contact us](/contact) for email delivery of resources
- Access materials through your account dashboard instead
- Visit our [resources page](/resources) for browser-viewable versions

## Browser-Specific Fixes

**Chrome:** Check chrome://settings/downloads for download location
**Firefox:** Check about:preferences#general for download settings
**Safari:** Check Preferences > General > File download location
**Edge:** Check edge://settings/downloads for download settings

Still having issues? [Contact our technical support](/contact) with details about your browser, device, and specific error messages.
