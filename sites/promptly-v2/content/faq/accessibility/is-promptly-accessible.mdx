Yes, Promptly is designed to be accessible and follows WCAG 2.1 guidelines for inclusive web design.

## Accessibility Features

**Screen reader support:** Full compatibility with JAWS, NVDA, and VoiceOver
**Keyboard navigation:** Complete functionality without a mouse
**High contrast:** Text meets AA colour contrast standards
**Scalable text:** Works with browser zoom up to 200%
**Focus indicators:** Clear visual focus for all interactive elements

## Assistive Technology Support

**Voice input:** Works with Dragon NaturallySpeaking and similar tools
**Switch navigation:** Compatible with external switch devices
**Eye tracking:** Functions with eye-tracking input systems
**Mobile accessibility:** VoiceOver (iOS) and TalkBack (Android) support

## Content Accessibility

**Plain English:** Clear, jargon-free interface text
**Consistent layout:** Predictable navigation and structure
**Error messaging:** Clear, helpful error descriptions
**Instructions:** Step-by-step guidance for all features

## Ongoing Improvements

We regularly test with:
- Screen reader users
- Keyboard-only navigation
- High contrast and magnification tools
- Voice control systems

## Getting Help

If you encounter accessibility barriers:
- [Contact our accessibility team](/contact)
- Report specific issues you're experiencing
- Request alternative formats or workflows
- Suggest improvements

We're committed to making Promptly usable by all teachers, regardless of ability.
