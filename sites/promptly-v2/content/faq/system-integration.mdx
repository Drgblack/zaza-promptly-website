Currently, Promptly works as a standalone tool that integrates with your existing workflow through copy-and-paste. Direct MIS integration is on our development roadmap.

## Current Integration Approach

**Copy-paste workflow:** Generate comments in Promptly, then copy into your school's system
**Universal compatibility:** Works with any reporting system (SIMS, Bromcom, Arbor, etc.)
**No IT setup required:** Start using immediately without technical configuration
**Maintains school security:** No direct access to sensitive student databases

## Why Teachers Prefer This Approach

**Flexibility:** Use Promptly with any system your school adopts
**Security:** Your student data stays within your school's systems
**Speed:** Often faster than native system tools
**Quality:** Better AI specifically designed for education

## Popular School Systems We Work With

**SIMS:** Copy comments directly into report modules
**Bromcom:** Paste improved text into communication tools
**Arbor:** Enhance comments before adding to student records  
**SchoolPod:** Improve parent communication drafts
**iSAMS:** Professional comments for independent schools
**Scholarpack:** Enhanced communication for small schools

## Workflow Examples

**Report writing with SIMS:**
1. Open SIMS report module
2. Open Promptly in another browser tab
3. Generate professional comments in Promptly  
4. Copy-paste into SIMS fields
5. Review and customise as needed

**Parent emails with Bromcom:**
1. Start draft email in Bromcom
2. Write rough version in Promptly first
3. Get professional, empathetic version
4. Copy improved text to Bromcom
5. Send with confidence

## Benefits of Standalone Approach

**System independence:** Works regardless of what MIS your school uses
**Upgrade protection:** Continues working when schools change systems
**Multi-platform:** Use with email, websites, documents, any text field
**Testing flexibility:** Try different approaches without IT involvement
