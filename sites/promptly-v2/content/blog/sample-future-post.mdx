# Sample Future Post: Testing Auto-Publishing System

This is a test post to demonstrate how the auto-publishing system works. This post is currently in draft mode and scheduled for publication next Monday.

## How the Auto-Publishing Works

The auto-publishing system uses several components:

1. **Draft Mode**: Posts marked with `isDraft: true` won't appear on the site
2. **Scheduled Publishing**: Posts with a `publishDate` field will automatically publish when that date/time arrives
3. **GitHub Actions**: A weekly workflow checks for scheduled posts every Monday at 9 AM UTC
4. **API Endpoints**: Custom endpoints handle the publishing logic and site revalidation
