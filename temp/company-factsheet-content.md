## Product Overview

**Zaza Promptly** is an AI-powered communication assistant specifically designed for educators. Our platform helps teachers:

- Draft professional parent emails in seconds
- Generate personalized report comments
- Translate communications into 20+ languages
- Maintain warm, professional tone across all messages
- Save 2-5 hours per week on administrative tasks

## Key Features

### Smart Message Writer
- Context-aware AI trained on educational communications
- Tone adjustment (warm, professional, firm, neutral)
- Multi-language support with educational terminology
- Integration with existing school systems

### Report Comment Generator
- Curriculum-aligned comment suggestions
- Differentiation options for diverse learners
- Progress tracking integration
- Export to common formats (Word, PDF, Google Docs)

### Parent Communication Tools
- Email templates for common scenarios
- Phone call script generators

- Privacy-first approach (no student data stored)
